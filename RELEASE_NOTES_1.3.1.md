# BOXROOM MusicEX 1.3.1

- Fixes user-added album screenshots not appearing when **Use embedded music metadata** is enabled.
- Keeps BOXROOM's `extra_0`, `extra_1`, ... screenshot filenames contiguous even when embedded metadata artwork is present.
- Prevents a low-resolution embedded cover tagged as `Other` from appearing as interior/screenshot artwork.
- Refreshes matching live album cases after metadata and artwork are rebuilt.

This release targets the current BOXROOM album APIs from the October 1, 2026 game export.
